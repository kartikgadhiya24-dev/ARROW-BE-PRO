## 🕹️ How to Play

| Action | Key |
|--------|-----|
| Move Left | `←` Arrow / `A` |
| Move Right | `→` Arrow / `D` |
| Move Up | `↑` Arrow / `W` |
| Move Down | `↓` Arrow / `S` |
| Pause | `Space` / `Esc` |
| Mobile | Swipe / On-screen buttons |

## ✨ Features

- 🏹 **Smooth Arrow Player** — with trail effects, tilt animation, and glow
- 🌟 **Multiple Collectibles** — Stars, Gems, Diamonds, Power-ups
- ⚡ **Power-up System**
  - 🛡️ **Shield** — Absorbs one hit, invincibility frames
  - ⚡ **Speed Boost** — Moves 1.6x faster
  - 🧲 **Magnet** — Pulls nearby collectibles automatically
- 💥 **Obstacle Types**
  - Red Spikes (triangles) — dodge these!
  - Wall Barriers — narrow gaps to pass through
  - Rotating Star Obstacles — spin and block your path
- 🔥 **Combo System** — Collect rapidly for multiplied points
- 📈 **Level Progression** — Every 250 points = next level, obstacles speed up
- ✨ **Particle Effects** — Explosions on hits and collects
- 🌌 **Animated Starfield Background**
- 📱 **Mobile Friendly** — Touch swipe + on-screen D-pad
- 💾 **Best Score Saved** — via localStorage
- 🎨 **Neon Cyberpunk UI** — dark mode, glow effects, Orbitron font
